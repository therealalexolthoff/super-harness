# Super Harness: A Reference For Aspiring AI Engineers

This harness demonstrates, with careful commenting throughout, the basics of building an Agentic Harness.

The target audience is anyone learning about AI Engineering.


Have a suggestion on how to improve this project? PRs are more than welcome.

## Set Up Guide

1. Clone the repo and 'cd' into it. 
2. Create a venv by initializing uv. This will also add the dependencies.
```
uv init
```
4. Copy '.env.example' to '.env' and fill in your OpenAI API key.
